## Corpus notes

`fixtures/hostile-url-params.json` contains 121 named entries. Each entry records either a literal
value or a repeat descriptor (for the 10 KiB cases); `rawQuery: true` marks values that must remain
percent-encoded so URLSearchParams performs exactly one attacker-controlled decode. The parser
corpus records the expected `ParseResult` for dangerous schemes, credentials, nested encodings,
oversized input, and sanitized labels.

The provider test creates a committed-fixture-backed 1,000-item response without contacting
Wikimedia. Invalid types and namespaces are mixed into valid items, and the guard audit checks the
returned `Poi` values again before the `POI_MAX` slice is accepted.
