## Smoke contract prepared by this worktree

`npm run smoke:providers` is intentionally a manual-only command. It:

- exits successfully with a notice and makes zero requests when `CI` is set;
- loads every currently enabled registry layer and schedules one tile request per layer;
- adds exactly one Tokyo Station geosearch and one Tokyo Station summary request;
- refuses to start if the planned total exceeds 12 requests (the default flag-off registry plans
  11 requests: 9 GSI tiles + 2 Wikimedia requests);
- sends `User-Agent` and `Api-User-Agent` headers, uses sequential requests at most 1 request/second
  (at least 1 second between request starts), accepts tile HTTP 200 or coverage/no-data HTTP 404,
  and aborts on the first other error;
- prints a table for completed rows and a failure table for the first error.

The live command was **not run** as part of this preparation task.
